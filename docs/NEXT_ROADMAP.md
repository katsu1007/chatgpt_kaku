# KAKU NEXT — Development Roadmap

## 最優先：品質の土台

- [ ] 現行機能・画面・データ形式の棚卸し
- [ ] 代表案件を使った保存／再読込／編集／出力の回帰確認
- [ ] iPhone Safari と PC ブラウザで主要操作を確認
- [ ] 図面解析の評価用データセットと正解値を整備
- [ ] 解析結果に「自動認識」「人が修正」「未確認」の状態を付ける

## 第1段階：図面解析・数量拾い

- [ ] JWW / DXF / PDF / 画像の入力経路を形式別に整理
- [ ] レイヤー、線種、HATCH、塗りつぶし、ブロック・シンボルの取り扱いを検証
- [ ] 部屋境界の閉合、壁厚、斜め壁、柱、段差、複雑形状の認識を改善
- [ ] 寸法文字・縮尺・単位の読み取りと、実寸との整合確認
- [ ] トイレ器具、洗面、便器、尿器、照明、コンセント等の記号辞書を評価
- [ ] 面積・周長・壁面積・開口控除の計算根拠を図面上で追跡可能にする

## 第2段階：改修工事の積算

- [ ] 現況図と改修図を対応付け、撤去・新設・流用を区別
- [ ] 床・壁・天井・建具・下地・設備・電気の工種別数量を統合
- [ ] 材料ロス、施工手間、搬出・処分、養生、諸経費を明細化
- [ ] 数量の出典（図面・部屋・手入力・標準値）と修正履歴を保持
- [ ] 単価・原価・掛率・利益・税率を案件ごとに管理

## 第3段階：設備計画・現場運用

- [ ] 部屋用途・広さ・家具配置を踏まえた照明・スイッチ・コンセント配置案
- [ ] 配置案の理由、回路・配線距離、必要確認事項を表示
- [ ] 現場での寸法追記、写真・メモ、手書きスケッチを案件に紐付け
- [ ] PDF / CSV / Excel の帳票品質と印刷レイアウトを整備

## 第4段階：販売品質

- [ ] データのバックアップ・復元・端末移行
- [ ] 入力ミス防止、エラー表示、操作ガイド
- [ ] 権限・データ保護・ライセンス・同梱ライブラリの確認
- [ ] 実案件での受入テストと、見積根拠を説明できる帳票
- [ ] 対応環境・制限・料金モデルを明確化

## 評価ルール

- 同じ図面セットを現行版と改善版の両方に入力する。
- 正解値（部屋数、面積、周長、開口、器具数、工事項目数量）を先に確定する。
- 完全一致だけでなく、誤差率、見逃し、誤検出、手修正時間を記録する。
- 「読み込めた」だけでは合格にしない。数量と見積への反映まで確認する。
